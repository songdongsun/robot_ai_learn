## 1. DH 参数到底在做什么？

上一节学习了旋转矩阵 R、平移向量 t，以及把它们组合起来的齐次变换矩阵 T。示例直接给出了旋转角度和原点位置。

这一节的问题是：**已知机械臂的结构尺寸和各个关节角度，怎样计算末端相对于底座的位置和朝向？** 这就是正运动学。

DH（Denavit–Hartenberg）参数法，是一套给机械臂各段建立坐标系，再用四个参数描述相邻坐标系关系的方法。最后得到的仍然是齐次变换矩阵。

学习顺序可以是：

```text
关节角度与机械结构尺寸
        ↓
建立坐标系，填写 DH 参数表
        ↓
计算每一段的齐次变换矩阵
        ↓
将各段矩阵连乘
        ↓
得到末端相对于底座的位姿
```

## 2. 先看两根杆、两个转动关节

假设机械臂在屏幕的 xy 平面内运动：x 向右，y 向上，z 从屏幕朝向我们。

```text
       +y
        ↑
        |
        O ───────── A ───────── B       → +x
          第一根杆      第二根杆
            L₁           L₂

        O：第一个关节
        A：第二个关节
        B：机械臂末端
```

O、A 两个关节都绕垂直屏幕的轴旋转。B 是末端点，不是第三个关节。

在这个例子里建立三套坐标系：

- 坐标系 0：原点在 O，固定在底座。
- 坐标系 1：原点在 A，x₁ 沿第一根杆从 O 指向 A 的方向。
- 坐标系 2：原点在 B，x₂ 沿第二根杆从 A 指向 B 的方向。
- 三根 z 轴都朝向我们，各自的 y 轴由右手规则确定。

注意：x₁ 的箭头从 A 出发，但它的正方向与 O→A 一致；x₂ 的箭头从 B 出发，但它的正方向与 A→B 一致。

杆转动时，附着在杆上的坐标系也跟着转。

## 3. 平面例子先理解两个参数：角度 θ 与长度 a

从 O 到 A，需要知道：

- 第一根杆相对底座 x₀ 的方向：θ₁。
- 第一根杆的长度：a₁ = L₁。

从 A 到 B，需要知道：

- 第二根杆相对第一根杆转了多少：θ₂。
- 第二根杆的长度：a₂ = L₂。

例如：

```text
                   B
                   ↑
                   | 第二根杆
                   |
        O ──────── A
          第一根杆
```

此时 θ₁ = 0°，θ₂ = 90°。

**θ₂ 是第二根杆相对于第一根杆的转角，不是相对于底座 x 轴的角度。** 如果 θ₁ = 30°、θ₂ = 90°，第二根杆相对于底座 x 轴的方向就是 120°。

本例零位约定为两根杆都沿 +x 伸直，正角度遵循右手定则。

## 4. 为什么三维机械臂需要四个参数？

真实机械臂的相邻关节轴之间，可能存在沿轴方向的偏移，也可能存在方向上的扭转。因此，文档采用的标准 DH 参数有四个：

| 参数 | 名称 | 按本文标准 DH 约定理解 |
| --- | --- | --- |
| θᵢ | 关节角度 | 绕 zᵢ₋₁，从 xᵢ₋₁ 转到 xᵢ 的有向角 |
| dᵢ | 关节偏距 | 沿 zᵢ₋₁，从上一原点到与 xᵢ 交点的有向距离 |
| aᵢ | 连杆长度 | 沿 xᵢ，从 zᵢ₋₁ 到 zᵢ 的距离 |
| αᵢ | 连杆扭角 | 绕 xᵢ，从 zᵢ₋₁ 转到 zᵢ 的有向角 |

先记住操作类型：

> θ、d 管绕 z 转和沿 z 移；a、α 管沿 x 移和绕 x 转。

这里的“连杆长度”有严格的几何含义，不一定等于机械臂外壳看起来的总长度。

对于转动关节，通常 θᵢ 是随运动变化的量，dᵢ、aᵢ、αᵢ 由结构与建系确定；对于移动关节，通常 dᵢ 是变化量，θᵢ 固定。关节读数与 DH 参数之间也可能存在零位偏置。

## 5. 为什么偏偏选这些轴？

DH 坐标系不能任意摆放，需要按规则建立。这里沿用原文的标准 DH 编号：

1. 第 i 个关节的运动轴是 zᵢ₋₁。转动关节绕它转，移动关节沿它移动。
2. xᵢ 沿相邻 zᵢ₋₁、zᵢ 的公垂线方向，即同时垂直两根轴的连接方向。
3. 原点 Oᵢ 放在 xᵢ 与 zᵢ 的交点。
4. yᵢ 按右手规则确定。

相交轴的公垂线长度为零，平行轴的公垂线位置有选择自由；末端坐标系也需要按任务与建系规则选定。因此，实际建系时可能存在不止一种合法选择。

**正因为按 DH 规则放置了坐标系，相邻坐标系的关系才能用这四个参数描述。不能把任意放置的两个坐标系直接套入四参数公式。**

不同资料可能采用不同下标，或采用改进 DH。本文只沿用当前教程的标准 DH 公式，不混用不同约定。

## 6. 两段平面机械臂的 DH 参数表

在本例的建系方式下：

- 机械臂在同一个 xy 平面内运动，沿 z 没有偏移，因此 d₁ = d₂ = 0。
- 各根 z 轴平行、同向，因此 α₁ = α₂ = 0。
- a₁、a₂ 分别等于两根杆的长度。

| 段 | θ | d | a | α |
| --- | --- | --- | --- | --- |
| 第一段 | θ₁ | 0 | L₁ | 0 |
| 第二段 | θ₂ | 0 | L₂ | 0 |

对应代码：

```python
T_01 = dh_matrix(theta1, 0, L1, 0)
T_12 = dh_matrix(theta2, 0, L2, 0)
```

函数参数顺序是：

```python
dh_matrix(theta, d, a, alpha)
```

代码中的角度使用弧度，长度使用米。例如 90° 要写成 `np.radians(90)`。

## 7. 四个参数怎么得到齐次变换矩阵？

标准 DH 公式为：

$$
T_{i-1,i}=
\operatorname{Rot}_z(\theta_i)
\operatorname{Trans}_z(d_i)
\operatorname{Trans}_x(a_i)
\operatorname{Rot}_x(\alpha_i)
$$

这些因子都是 4×4 齐次变换矩阵。可以从旧坐标系开始，按当前局部坐标轴依次建立下一套坐标系：

1. 绕当前 z 轴转 θ。
2. 沿当前 z 轴移动 d。
3. 沿旋转后的当前 x 轴移动 a。
4. 绕当前 x 轴转 α。

这是描述坐标系关系的一种构造过程，不是在要求机械臂真实执行四个动作。

**区分两个视角：按当前局部轴建系时，可以按上面的顺序理解；当矩阵乘积作用于一个列向量时，右边的因子先参与运算。不要把四步都当成绕固定底座轴操作。**

展开后，得到代码中返回的矩阵：

$$
T_{i-1,i}=\begin{bmatrix}
\cos\theta&-\sin\theta\cos\alpha&\sin\theta\sin\alpha&a\cos\theta\\
\sin\theta&\cos\theta\cos\alpha&-\cos\theta\sin\alpha&a\sin\theta\\
0&\sin\alpha&\cos\alpha&d\\
0&0&0&1
\end{bmatrix}
$$

它仍然具有熟悉的结构：左上角是旋转矩阵，最后一列前三项是下一坐标系原点在上一坐标系中的位置。

### 平面例子的简化形式

令 d = 0、α = 0：

$$
T=\begin{bmatrix}
\cos\theta&-\sin\theta&0&a\cos\theta\\
\sin\theta&\cos\theta&0&a\sin\theta\\
0&0&1&0\\
0&0&0&1
\end{bmatrix}
$$

其中平移部分为：

$$
t=\begin{bmatrix}a\cos\theta\\a\sin\theta\\0\end{bmatrix}
$$

几何意义很直接：一根长 a 的杆朝 θ 方向伸出去，它的端点在 (a cosθ, a sinθ, 0)。

## 8. 为什么把两段矩阵乘起来？

按代码的实际用法：

- T_01 把坐标系 1 中的坐标换算到坐标系 0。
- T_12 把坐标系 2 中的坐标换算到坐标系 1。
- 所以 T_02 = T_01 @ T_12 把坐标系 2 中的坐标换算到坐标系 0。

```python
T_02 = T_01 @ T_12
```

若用末端原点的齐次坐标表示：

$$
\begin{bmatrix}p_0\\1\end{bmatrix}
=T_{01}T_{12}\begin{bmatrix}0\\0\\0\\1\end{bmatrix}
$$

末端原点在自己的坐标系中是 (0, 0, 0)，换算到底座后，结果就是末端位置。

因此代码可以直接提取总矩阵最后一列的前三项：

```python
pos_final = T_final[:3, 3]
```

`T_01` 的名字容易与“从 0 到 1”混淆。这里应以乘法关系为准：它表示坐标系 1 相对于坐标系 0 的位姿，坐标换算方向是 1 → 0。

## 9. 用具体例子验证

取 L₁ = L₂ = 1 米、θ₁ = 0°、θ₂ = 90°。

第一根杆沿底座 +x 伸出 1 米，因此 A 在 (1, 0, 0)。第二根杆再朝 +y 伸出 1 米，因此末端 B 在 (1, 1, 0)。

也可以用平面几何直接计算：

$$
x=L_1\cos\theta_1+L_2\cos(\theta_1+\theta_2)
$$

$$
y=L_1\sin\theta_1+L_2\sin(\theta_1+\theta_2),\qquad z=0
$$

代入得到 x = 1、y = 1、z = 0，与 DH 矩阵连乘一致。末端方向相对于底座绕 z 转了 θ₁+θ₂ = 90°。

这里图中的“向上”指图上的 +y，不一定是现实中重力的反方向。原教程中“指天”的注释，应结合模型坐标定义理解。

## 10. 当前需要掌握的要点

1. DH 是建系和描述相邻坐标系关系的方法，最终结果仍是齐次变换矩阵。
2. θ、d 对应绕 z 转和沿 z 移；a、α 对应沿 x 移和绕 x 转。
3. 四参数公式成立的前提是按对应 DH 规则建立坐标系。
4. 平面两连杆例子中 d、α 都为零，可以先用 θ 和 a 理解几何关系。
5. 第二个关节角度是相对前一段的角度，不是相对底座的绝对角度。
6. 每一段的变换依次连乘，就能得到末端相对于底座的位姿。

与上一节的联系：**上一节直接给出 R 和 t；这一节根据关节角度与机械结构尺寸，用 DH 参数计算 R 和 t。**
