**2. “通过学习决定动作”，到底是什么意思？**

拿你熟悉的机械臂接近杯子举例。

以前我们讨论的控制流程，可以由人明确设计：

```text
确定杯子位置
    ↓
设计夹爪目标位姿
    ↓
逆运动学求关节角
    ↓
轨迹规划
    ↓
控制器执行
```

强化学习则引入一个叫作**策略**的东西。你先把它理解为：

> 根据当前观察，决定下一步动作的规则。这个规则可以由神经网络表示，并通过训练调整。

例如：

```text
观察：
机械臂当前关节角是多少？
夹爪在哪里？
杯子在哪里？
          ↓
策略
          ↓
动作：
下一步让夹爪向哪个方向移动？
```

这里的动作也可能是目标关节角、关节速度或力矩，**取决于环境如何定义动作接口，不能一概认为策略直接输出力矩。**

训练时，机器人反复执行动作，环境给出反馈：

```text
观察当前情况
    ↓
策略选择动作
    ↓
机器人运动，环境发生变化
    ↓
获得新的观察与奖励
    ↓
训练算法利用这些经历更新策略
    └────────────→ 再尝试
```

例如，可以设计“接近目标获得奖励、成功抓起获得更大奖励、碰撞或掉落受到惩罚”。这些只是帮助理解的例子，不是文档中 CooHOI 奖励函数的逐项定义。

**强化学习追求的是长期累计奖励，因此它要学习一连串动作，而不只是判断眼前这一张图。**

**3. 和你前面学的知识怎么接起来？**

| 前面学过的内容 | 在学习型机器人系统里的作用 |
|---|---|
| 正运动学 | 根据关节状态计算末端在哪里 |
| 逆运动学、雅可比矩阵 | 当策略输出末端目标或速度时，帮助转换成关节运动要求 |
| 动力学 | 描述力矩怎样引起运动，也是物理仿真的基础 |
| PID 等控制器 | 当策略输出目标关节角等指令时，负责跟踪目标 |
| 电机、编码器、开发板 | 执行动作、采集反馈、运行相应程序 |
| 相机、YOLO、SAM、深度估计 | 提供目标与环境的观测信息 |
| 本章的策略学习 | 根据观测，学会选择有利于完成任务的动作 |

一个便于理解的组合是：

```text
04：视觉感知 ───────┐
                   ↓
03：关节传感器 → 当前观察
                   ↓
05：学习到的策略 → 目标关节角
                   ↓
02：控制器 → 力矩指令
                   ↓
03：驱动器、电机 → 机器人运动
                   ↓
              获得新的观察
                   └────→ 回到策略
```

**这是“策略输出目标关节角”的一种架构。**实际项目可能采用其他接口，并不是所有项目都会把 YOLO、SAM、逆运动学、PID 全部串进去。

尤其在仿真中，环境可以直接提供物体位置、关节状态等信息，所以训练策略时未必需要先运行视觉模型。

**4. 这和你已经接触的 YOLO 训练有什么不同？**

用最常见的训练方式比较：

| | YOLO 检测训练 | 机器人强化学习 |
|---|---|---|
| 学习材料 | 图片及人工标注的类别、框 | 与环境交互得到的经历 |
| 输出 | 类别、检测框等 | 动作或动作分布 |
| 反馈 | 预测与标注之间的误差 | 奖励、后续状态等 |
| 核心目标 | 检测准确 | 连续行动后完成任务 |

**深度学习和强化学习不是互斥的两种东西。**当策略等组成部分使用深度神经网络，并通过强化学习方法训练时，就是深度强化学习。

你前面已经使用了深度学习模型；这一章的变化，主要是开始用学习方法解决**行动决策**。

**5. 对你来说，这章应该怎么学？**

按仓库顺序走，但在读第一个搬运项目之前，先补齐五个概念：

1. **观察**：机器人当前能获得什么信息？
2. **动作**：策略到底控制什么量？
3. **奖励**：怎样评价任务做得好不好？
4. **策略**：怎样从观察得到动作？
5. **环境**：谁负责执行动作、模拟物理变化并返回反馈？

接着看 CooHOI 时，就围绕这五个问题读，而不是先记安装命令。主文档使用 Isaac Gym，并给出了 CUDA 和 Linux 风格的命令，**不能直接当成你目前 Windows、CPU 版 `embodied` 环境的启动教程**。

你这一章最重要的进步，是能把以前学的“目标给定以后，机器人如何运动”，接到新的问题上：**面对当前环境，目标和动作应该怎样由策略决定。**
